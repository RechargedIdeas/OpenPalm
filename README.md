# Agent Harness

Local-first, verification-first AI agent harness for real estate agents.

## Quick start (CPU-only, no GPU required)

```bash
cd sidecar
pip install -r requirements.txt
python3 gui.py
```

This starts the server if needed and opens the GUI. Use Start / Stop / Reset in the header.
