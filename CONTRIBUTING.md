# Contributing

This repository is maintained by both humans and AI agents.

## Quick start

```bash
cd sidecar
pip install -r requirements.txt
python3 gui.py
```

## Rules

- Verification cannot be turned off
- Default is local / CPU-only
- No listing-portal scrapers
- Max six top-level nav items
- Do not commit secrets or model weights

See AGENTS.md for the full agent workflow.
