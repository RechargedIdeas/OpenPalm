# Contributing

This repository is maintained by humans and AI agents. The product is a simple, verification-first AI assistant for everyone — not only one profession.

## Quick start

```bash
cd sidecar
pip install -r requirements.txt
python3 gui.py
```

## Rules

- Verification cannot be turned off
- Default is local / CPU-only; cloud requires a clear warning
- No scrapers
- Maximum six top-level navigation items
- Plain language in the UI; no unexplained technical terms
- Do not commit secrets or model weights
